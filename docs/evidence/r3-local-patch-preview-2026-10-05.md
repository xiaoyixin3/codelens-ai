# R3：Java 局部补丁预览后端证据（2026-10-05）

## 交付范围

新增批准方案之后的只读预览后端。复用 ReuseDecisionStore、ReuseDecisionService、
现有全仓库索引的文件 hash/符号、JavaParser 和脱敏规则，未重写审查引擎。
调用者提供已索引 Head 原文和建议的行编辑，服务生成具体 unified diff、前后 hash、
实际变更符号、审批版本与候选证据引用。**不是从目标自动生成修复方案**。

入口：`POST /api/v2/reviews/{reviewRunId}/reuse-planning/patch-preview`。
沿用现有共享管理员认证和 installation 范围；未配置管理员令牌时拒绝开放。
这不等于独立人员身份认证或新的多租户授权体系。审批不可由预览接口自行生成。
接口未接入 gold 标注页面，未向盲标响应增加模型预测或方案。

## 实际保护

- 审批 ID/版本必须是当前版本，重新校验冻结调查、候选证据、所选方案及预算。
- run 必须 completed，安装有效、仓库仍被选择，两侧快照 ready 且身份完整匹配。
  同 PR 已有更新的持久化 run 时拒绝；这是本库已知历史，不是远端实时版本校验。
- 原文 UTF-8 SHA-256 必须等于生产索引的 Head 文件 hash，禁止伪造原文。
- 请求最多 1 MiB、1–3 个批准文件、每文件 256 KiB/5,000 行、每文件 10 处编辑、
  每处最多 60 个替换行、合计删除+增加最多 120 行、diff 最多 64 KiB。
  文件/实际变更符号同时受审批预算限制；每文件索引符号上下文最多 200 个。
- 路径仅支持安全的 ASCII 相对 `.java` 路径；不支持新建、删除、移动文件。
  支持一致 LF/CRLF 和缺少末尾换行；混合换行、Unicode 转义及非法 UTF-16 拒绝。
- 编辑必须严格位于已有方法/构造函数体内部，不支持一行方法体。
  AST 检查拒绝签名、注解、字段、类型、导入和新增声明的变化；实际改变的函数体
  必须唯一映射到冻结符号，并在所选方案中。不是依赖调用者填写的变更数量。
- 大于 8 行的方法体，删除覆盖超过 35% 时拒绝；这是保守文本启发式，短方法
  不适用此比例，不能证明“没有重写逻辑”、候选真的被调用或行为兼容。
- 检出敏感内容时拒绝整个预览，而非脱敏后返回一个不再可应用的伪补丁。
- PostgreSQL 技能约束用于有界、只读、可重复读短事务：查询超时 4 秒，事务
  超时 5 秒。解析和生成 diff 在事务外，返回前再次读取上下文，变化则不给 diff。
  该二次读取不是锁住远端 PR 或未来应用动作的授权。
- 不存源码、diff 或模型输出，不写仓库/索引/审批，不执行仓库脚本，不调用模型、
  GitHub 或发布器。响应 `Cache-Control: no-store`；错误只有限定通用错误码。

所有成功响应仍固定 `publicationAllowed=false`、`automaticApplyAllowed=false`、
`verifiedFix=false`、`publicBehavioralContractVerified=false`，并显式列出未验证事项。
只读响应本身含补丁正文，代理/客户端也应禁用正文记录并使用受保护传输。
请求字节限制不替代连接超时、速率限制和部署侧并发资源隔离。

## 测试与失败记录

LocalPatchPreviewTest（11 项）：冻结证据/hash、越界文件/符号、实际数量预算、
声明注入、敏感内容、非法编辑/编码、广泛重写、输入限额及换行兼容。
对合成临时目录实际执行 `git apply --check` 验证 diff 格式，不应用修改、不执行
Java 或被审查项目代码，并核对原文件未变。

PatchPreviewControllerTest（5 项）：先认证/身份检查后读正文、大小限制、错误码
和 no-store、审批二次读取冲突不给 diff、伪原文不泄漏。

PatchPreviewIntegrationTest（7 项）：真实隔离 PostgreSQL，真实 BuildModelDetector
和 JavaSemanticAdapter 建立索引、持久化调查/审批后验证预览；安装/文件范围、
新审批、新 run、停用安装/仓库、索引身份篡改/文件失败、快照删除均拒绝。
成功预览前后审计行指纹一致，源文件与冻结符号是实际适配器结果，不是手填索引。
测试里的审批为明确合成 fixture，不是给用户真实仓库伪造批准。

第一次编译中的泛型范围访问已修正；首次测试暴露禁用 JavaParser token 存储会
丢失必要范围，已恢复默认位置支持。后续 11 项单测以及 API/数据库针对性回归
通过，没有放宽符号锚定。失败的首次运行不计入通过证据。

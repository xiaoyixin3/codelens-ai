# 模型输入计划与持久化预算：工程证据

日期：2026-10-04。候选 pipeline：java.16；前向迁移：022。
当前本机公网服务仍是 java.13 / schema 019，未升级、未接入收费模型。

## 本轮完成范围

复用 Java LlmClient、原 llm_calls 审计、JdbcStore 短事务、Redactor 和任务租约检查。
没有新增审查规则、模型 Prompt 阶段、语言、外部写入或仓库代码执行。
本轮是桌面方案顺序 4 的输入安全与预算基础，不是完整分块 Agent 的交付。

1. 确定性单块 ContextPlan：精确 Base/Head、策略哈希、任务、纳入文件路径、脱敏
   patch 的可用/实际长度及哈希、遗漏路径/原因、整包请求字节数及 SHA-256。
   对象字段规范排序，避免 Map 插入顺序影响指纹。请求包含模型名、system/user
   messages、JSON 转义、response_format 等实际发送内容，而不只计 diff。
2. 先脱敏完整字符串，再截取到完整换行边界；空 patch、文件上限、patch 预算和
   部分 patch 均显式记录。模型也能看到覆盖清单。对字段值脱敏后才编码 JSON，
   不对编码后的嵌套 JSON 做可能破坏引号边界的正则替换。
3. 每个实际发送尝试先事务登记 reserved 调用和不可更新的元数据计划，再发 HTTP。
   请求正文、源码、模型回复和凭据不写入该计划表。每次重试/备用提供方单独计费。
4. 每个 run 的锁内汇总检查持久化次数和字节占用；并发不能同时花最后一份预算。
   预算上限与首次计划一致，重新启动客户端不能清零；无法可靠计量的旧遥测拒绝。
   计划与当前 run 的版本、状态、Base/Head、有效策略哈希交叉核验。
5. 发送前的占用不能退款。崩溃、取消或数据库提交结果不明，可能占用未实际发送的
   额度，这是有意的保守设计；不把 reserved 当作已证明的远端成功。
   仍有 reserved 或遥测已被保留策略清理时，整个 run 拒绝新模型请求；不得把
   未知结果当作失败后重发。预算计划独立保留到 run 删除，不随 llm_calls 清理，
   防止遥测 TTL 静默恢复额度；run 删除级联清除该元数据。
6. 预算登记或结果审计失败不作为普通 provider 失败重试；成功/失败记录保留原
   请求 hash 和字节数，不再把失败写成空请求。仅保存有界错误码，不记录远端正文。
7. 每次预算登记前、发送前及结果审计后检查当前任务持有权。失去租约不发送后续
   请求，已有预占保留。审查引擎明确展示模型失败/预算拒绝，不吞掉租约失效。
8. 语义覆盖成功不会抹掉模型输入遗漏/失败限制。风险模型复用本轮选中的语义
   impact，而不是总是使用 changed-file fallback 的 impact。

兼容环境名 LLM_MAX_INPUT_CHARS_PER_RUN 实际限制整包 UTF-8 请求字节，**不等于
token 数、供应商上下文窗口或真实费用上限**。服务账户的费用限额仍需独立配置。

所有遗漏路径、仅元数据无源码、字段顺序无关的稳定指纹。

LlmClientTest：仅本机模拟 HTTP 服务；每次 503 重试单独预占、失败仍保留 hash
和字节；预算拒绝零发送；远端成功后审计失败不再次发送；实际接收字节/hash 与

## 安全和发布边界

仅隔离测试库和合成样例；本轮不读取真实模型密钥、不向模型外发源码、不执行
被审查仓库脚本、不变更 GitHub 评论或公网数据库、不生成历史伪计划。
新源码必须升级 schema 022 后启动，不允许旧/新 Worker 混跑。当前 trial 镜像
引用保持原样。PostgreSQL 技能的短事务约束用于预算锁：网络调用不在事务中，
锁等待和语句有单独超时。

## 未完成，不可冒充退出条件

- 现在是明确的一块输入计划；超整包预算诚实降级，不自动切成多块。
- 多块计划、加密结果保存、独立重试/结果重用和整 run 的可重放仍未实现。
- 尚无供应商 tokenizer/上下文窗口和输出 token/字节硬限制、实际成本校准。
- 完整模型/提供方/策略有效配置快照与自动重审仍待实现；当前绑定策略不替代它。
- 单次在途请求不能与租约取消原子绑定；不能撤回已被供应商接收的请求。
- 数据库回滚可能丢失后于备份的预算占用，恢复仍须隔离队列、核对供应商账单，
  不能声称数据库预占保证跨旧快照费用去重或 exactly-once。
- 独立标签、Phase 0 时间研究、Phase 1 精度、真实模型质量、局部补丁及验证沙箱
  仍按原基线验收。自动测试不替代真实精确率、召回率和节省时间证据。
